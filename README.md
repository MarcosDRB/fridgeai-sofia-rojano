# FridgeAI

Prototipo web para ayudar a reducir el desperdicio de alimentos: el usuario registra lo que tiene en casa, explora recetas y organiza un menú semanal y su lista de compras.

**Autora:** Sofía Rojano

## Cómo probarlo

Abre `index.html` directamente en un navegador. No requiere instalación ni servidor local.

## Qué incluye

- Registro de ingredientes y búsqueda de recetas por coincidencia.
- Filtros de tiempo, dificultad y tipo de comida.
- Detalle de recetas, favoritos y menú semanal.
- Lista de compras organizada por categorías.
- Preferencias guardadas en el navegador.
- Diseño adaptable a móvil y escritorio.

## Alcance de esta demostración

Las recetas y el menú automático usan datos de ejemplo; la aplicación todavía no se conecta a un modelo de inteligencia artificial, una base de datos ni un proveedor de autenticación. Las preferencias se guardan localmente en el navegador. Las fotografías se cargan desde Unsplash y necesitan conexión a internet.
